# Namaa storefront script

Public copy of the Namaa storefront script. Merchant stores load it from GitHub Pages so that file is not served by the Namaa app server.

https://craffo-technologies.github.io/namaa-storefront/namaa-storefront.js

The script still calls `https://nama.craffo.com` for storefront config and coupons. This repository has no secrets and is not the Namaa application.
